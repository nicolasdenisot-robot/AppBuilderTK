Your OROS 3-series developer toolkit enables:

    · to control the analyzer analysis while NVGate® is running,
    · to access results and signals stored in disk,
    · to send result into NVGate through a TCP channel

I. Resources

           The "NVGate_projects" directory contains some projects and measurements that
           must be imported in NVGate for some examples.

           The "NVGate_macro" directory contains one NVGate macro that must be copied in
           the NVGate macro directory, for one example.

II. Requirements

   You need to install "Microsoft Visual C++ 2010 Redistributable".
   https://www.microsoft.com/en-us/download/details.aspx?id=26999.

    The application enables to measure the time it takes to transfer results through the
    NVDrive®. The application is a dialog-based application with only one interface:

F227-C04-17  21/37
The CONNECTION button connects the n first inputs on the FFT analyzer and
connects the average spectrum of these channels to the waterfall.

The SETUP button sets up the number of lines of the FFT analyzer and the depth of

h. C++ Visual Studio 2015, NVGateSignalEditingDemo

A measurement can be composed of several records that are pieces of signal. The recorder
can be configured to write a single signal file or several files (parts) of fixed length, e.g., 64
seconds or 640 seconds. A record composed of several signal files is called a multi-part
signal.

The editing functionalities of the toolkit allow splitting a multi-part record in several
records or deleting one of them. To save disk space, irrelevant parts can be erased, meaning
that the corresponding file is removed, and the signal data is considered zero.

This example shows the Split, Remove Record and Erase features. It also explains how to
remove a channel.

         Project name: NVGateSignalEditingDemo.sln

         NVGateFile functions used:

                  NVGS_CreateNewMeasurement
                  NVGS_OpenMeasurement
                  NVGS_CloseMeasurement
                  NVGS_GetMeasurementPath

                  NVGS_GetRecordsVect
                  NVGS_OpenRecord
                  NVGS_CloseRecord

                  NVGS_StartRecord
                  NVGS_StopRecord
                  NVGS_WriteSampleBlock

                  NVGS_AddChannel
                  NVGS_SetRecordMultiPart
                  NVGS_GetRecordPartLength

                  NVGS_StartEditing
                  NVGS_StopEditing
                  NVGS_Split
                  NVGS_RemoveRecord
                  NVGS_RemoveChannel
                  NVGS_ErasePart

F227-C04-17  34/37
This example uses the "NVGateFile" DLL. The functions in this DLL that are used

in this example have a name that begins with NVGS_. They enable to get
information from an oros signal (since V17), with no need of NVGate®.

The timeline shows the list of records and parts for each record. The starting and ending
dates relatively to the record is written between square brackets.

Split: select a part and click on Split record to create a new record starting from this part.
Selecting part 0 has no effect.

Remove: select any part of a record and click on Remove record to remove the
corresponding record.

Erase: select a part and click on Erase part to remove it. The corresponding file is removed
and space is freed on the disk. Note that this has no impact on the Timeline list and on the

F227-C04-17  35/37
length of the signal. Browse the measurement directory to observe that the part file has
been removed.

Remove channel: select a channel on the list and click on remove channel to remove it.

You can open the measurement in NVGate to see the effects.
